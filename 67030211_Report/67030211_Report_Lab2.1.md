### ขั้นตอนที่ 3: โค้ด ESP-IDF สำหรับอ่านค่า ADC ดิบ (GPIO34)

🎥 **วิดีโอบันทึกผลการทดลอง (อ่านค่า ADC ดิบ):** [https://youtu.be/oHsqICxkGGE](https://youtu.be/oHsqICxkGGE)

กำหนดความละเอียด ADC เป็น 12-bit (0–4095) และ Attenuation 11dB (`ADC_ATTEN_DB_11`) ผ่านขา `ADC1_CHANNEL_6` (GPIO34):

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/adc.h"
#include "esp_log.h"

void app_main(void)
{
    // กำหนดความละเอียด ADC = 12 bit (0–4095)
    adc1_config_width(ADC_WIDTH_BIT_12);

    // กำหนด Channel 6 (GPIO34) และ Attenuation 11dB (ช่วงแรงดัน 0 - ~3.1V)
    adc1_config_channel_atten(ADC1_CHANNEL_6, ADC_ATTEN_DB_11);

    while (1) {
        int adc = adc1_get_raw(ADC1_CHANNEL_6);
        printf("ADC = %d\n", adc);
        vTaskDelay(pdMS_TO_TICKS(500));
    }
}
```
