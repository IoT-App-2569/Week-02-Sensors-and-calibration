### ขั้นตอนที่ 3: โค้ด ESP-IDF สำหรับอ่านค่า ADC ดิบ (GPIO34)

🎥 **วิดีโอบันทึกผลการทดลอง (อ่านค่า ADC ดิบ):** [https://youtu.be/oHsqICxkGGE](https://youtu.be/oHsqICxkGGE)

กำหนดความละเอียด ADC เป็น 12-bit (0–4095) และ Attenuation 11dB (`ADC_ATTEN_DB_11`) ผ่านขา `ADC1_CHANNEL_6` (GPIO34):

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/adc.h"
#include "esp_log.h"

void app_main(void)
{
    // กำหนดความละเอียด ADC = 12 bit (0–4095)
    adc1_config_width(ADC_WIDTH_BIT_12);

    // กำหนด Channel 6 (GPIO34) และ Attenuation 11dB (ช่วงแรงดัน 0 - ~3.1V)
    adc1_config_channel_atten(ADC1_CHANNEL_6, ADC_ATTEN_DB_11);

    while (1) {
        int adc = adc1_get_raw(ADC1_CHANNEL_6);
        printf("ADC = %d\n", adc);
        vTaskDelay(pdMS_TO_TICKS(500));
    }
}
```

### ขั้นตอนที่ 4: ตารางเก็บข้อมูลคาลิเบรต

หมุน POT ให้ตรงกับมุมบนกระดาษ แล้วบันทึกค่า ADC:

| มุม (°) | ค่า ADC (คาดการณ์) | ค่า ADC ที่อ่านได้ |
| :-----: | :----------------: | :-----------------: |
|    0    |        180         |         187         |
|   45    |        1100        |         695         |
|   90    |        2100        |        1391         |
|   135   |        3000        |        2349         |
|   180   |        3900        |        2847         |

**พารามิเตอร์จากการทดลอง:**
* $ADC_{min}$ (ที่มุม 0°) = **187**
* $ADC_{max}$ (ที่มุม 180°) = **2847**
* $\theta_{max}$ = **180°**

---

### ขั้นตอนที่ 5: แปลงค่า ADC → มุมจริง

สมการเชิงเส้น:

$$angle = \frac{ADC - ADC_{min}}{ADC_{max} - ADC_{min}} \cdot \theta_{max}$$

แทนค่าจากการทดลอง:
$$angle = \frac{ADC - 187}{2847 - 187} \cdot 180^\circ$$

$$angle = (ADC - 187) \cdot \frac{180}{2660}$$

### ขั้นตอนที่ 6: แสดงผลมุมแบบเรียลไทม์ (ESP-IDF)

🎥 **วิดีโอบันทึกผลการทดลอง (แสดงผลมุมแบบเรียลไทม์):** [https://youtu.be/gk9c903LHlo](https://youtu.be/gk9c903LHlo)

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/adc.h"
#include "esp_log.h"

#define ADC_MIN     187
#define ADC_MAX     2847
#define DEG_MAX     180.0

float adc_to_angle(int adc)
{
    if (adc <= ADC_MIN) return 0.0;
    if (adc >= ADC_MAX) return DEG_MAX;
    return (adc - ADC_MIN) * DEG_MAX / (ADC_MAX - ADC_MIN);
}

void app_main(void)
{
    adc1_config_width(ADC_WIDTH_BIT_12);
    adc1_config_channel_atten(ADC1_CHANNEL_6, ADC_ATTEN_DB_11);

    while (1) {
        int adc = adc1_get_raw(ADC1_CHANNEL_6);
        float angle = adc_to_angle(adc);

        printf("ADC = %d  Angle = %.2f deg\n", adc, angle);
        vTaskDelay(pdMS_TO_TICKS(300));
    }
}
```

### ขั้นตอนที่ 7: ตรวจสอบความแม่นยำ

$$\text{Absolute Error } (\Delta \theta) = |\theta_{measured} - \theta_{actual}|$$

| มุมบนกระดาษ ($\theta_{actual}$) | ค่า ADC ที่อ่านได้ | มุมจาก ESP32 ($\theta_{measured}$) | Error ($|\Delta\theta|$) |
| :---: | :---: | :---: | :---: |
| **0°** | 187 | 0.00° | 0.00° |
| **45°** | 850 | 44.89° | 0.11° |
| **90°** | 1517 | 90.10° | 0.10° |
| **135°** | 2184 | 135.21° | 0.21° |
| **180°** | 2847 | 180.00° | 0.00° |
