## 1. วัตถุประสงค์การทดลอง
1. เพื่อเข้าใจหลักการทำงานของตัวต้านทานปรับค่าได้ (Potentiometer: POT) ในการแปลงการเคลื่อนที่เชิงมุมทางกายภาพเป็นระดับแรงดันไฟฟ้าอนาล็อก
2. เพื่อฝึกการเขียนโปรแกรมอ่านค่าสัญญาณอนาล็อก (ADC) ด้วยเฟรมเวิร์ก ESP-IDF บนไมโครคอนโทรลเลอร์ ESP32 (ความละเอียด 12 บิต: ค่าดิบ 0–4095)
3. เพื่อเก็บข้อมูล Calibration คู่ลำดับระหว่างมุมจริงบนหน้าปัด ($\theta_{actual}$) กับค่าดิจิทัลดิบ (Raw ADC) และสร้างสมการเชิงเส้นแปลงค่า ($y = mx + c$)
4. เพื่อทดสอบความแม่นยำของระบบวัดมุมแบบเรียลไทม์ และประเมินค่าความคลาดเคลื่อน (Error Analysis) จากการหมุนทดสอบจริง

## 2. รายการอุปกรณ์และการต่อวงจร (Hardware Setup)

### 2.1 รายการอุปกรณ์
* บอร์ดไมโครคอนโทรลเลอร์ ESP32 (NodeMCU-32S)
* ตัวต้านทานปรับค่าได้ (Potentiometer) ชนิด Linear B ขนาด $10\text{ k}\Omega$
* สายต่อวงจร (Jumper Wires)
* แผ่นกระดาษหน้าปัดมุมวงกลม 0°–180° (แบ่งสเกลทุกๆ 30°) พร้อมเข็มชี้มุมติดแกนหมุน
* โปรแทรกเตอร์ ไม้บรรทัด และเทปกาว

### 2.2 ผังการต่อวงจร
* **ขาซ้าย POT (VCC):** ต่อเข้าไฟเลี้ยง `3.3V` ของ ESP32
* **ขาขวา POT (GND):** ต่อเข้ากราวด์ `GND` ของ ESP32
* **ขากลาง POT (Wiper):** ต่อเข้าขา `GPIO34` (ADC1 Channel 6) ของ ESP32

```text
    ESP32 Board                      Potentiometer 10k
   +------------+                    +-----------------+
   |       3.3V |--------------------| ขาซ้าย (VCC)    |
   |        GND |--------------------| ขาขวา (GND)     |
   |     GPIO34 |--------------------| ขากลาง (Wiper)  |
   +------------+                    +-----------------+
```

### ขั้นตอนที่ 3: โค้ด ESP-IDF สำหรับอ่านค่า ADC ดิบ

🎥 **วิดีโอบันทึกผลการทดลอง (อ่านค่า ADC ดิบ):** [https://youtu.be/oHsqICxkGGE](https://youtu.be/oHsqICxkGGE)

กำหนดความละเอียด ADC เป็น 12-bit (0–4095) และ Attenuation 11dB (`ADC_ATTEN_DB_11`) ผ่านขา `ADC1_CHANNEL_6` (GPIO34):

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/adc.h"
#include "esp_log.h"

void app_main(void)
{
    // กำหนดความละเอียด ADC = 12 bit (0–4095)
    adc1_config_width(ADC_WIDTH_BIT_12);

    // กำหนด Channel 6 (GPIO34) และ Attenuation 11dB (ช่วงแรงดัน 0 - ~3.1V)
    adc1_config_channel_atten(ADC1_CHANNEL_6, ADC_ATTEN_DB_11);

    while (1) {
        int adc = adc1_get_raw(ADC1_CHANNEL_6);
        printf("ADC = %d\n", adc);
        vTaskDelay(pdMS_TO_TICKS(500));
    }
}
```

### ขั้นตอนที่ 4: ตารางบันทึกข้อมูลเพื่อทำ Calibration (จากผลการทดลองจริงในคลิป)
หมุนเข็มชี้ไปยังมุมอ้างอิงบนกระดาษ (0°, 30°, 60°, 90°, 120°, 150°, 180°) แล้วบันทึกค่า Raw ADC จาก Serial Monitor:

| มุมจริงบนกระดาษ ($\theta_{actual}$) | ค่า Raw ADC ที่อ่านได้จริงจากคลิป | แรงดันไฟฟ้าโดยประมาณ (V) |
| :---: | :---: | :---: |
| **0°** | **0 – 8** (เฉลี่ย **0**) | 0 V |
| **30°** | **571** | 0.5 V |
| **60°** | **945** | 0.8 V |
| **90°** | **1391** | 1.1 V |
| **120°** | **1845** | 1.5 V |
| **150°** | **2349** | 1.9 V |
| **180°** | **2740** | 2.2 V |

**พารามิเตอร์จากการสอบเทียบ (Calibration Parameters):**
* $ADC_{min}$ (ที่มุม 0°) = **0**
* $ADC_{max}$ (ที่มุม 180°) = **2730**
* มุมสูงสุดที่ทำการวัด ($\theta_{max}$) = **180°**

---

### ขั้นตอนที่ 5: การสร้างสมการเชิงเส้นแปลงค่า ADC เป็นมุมจริง
จากความสัมพันธ์เชิงเส้นระหว่างค่าดิจิทัลของ ADC กับมุมองศาการหมุน:

$$\theta = \frac{ADC - ADC_{min}}{ADC_{max} - ADC_{min}} \times \theta_{max}$$

แทนค่าพารามิเตอร์ที่ได้จากการทดลอง:
$$\theta = \frac{ADC - 0}{2730 - 0} \times 180^\circ$$

$$\theta = ADC \times \frac{180}{2730}$$

### ขั้นตอนที่ 6: โค้ด ESP-IDF แสดงผลมุมแบบเรียลไทม์ฉบับสมบูรณ์ (ปัดเศษเป็นจำนวนเต็ม)

🎥 **วิดีโอบันทึกผลการทดลอง (แสดงผลมุมแบบเรียลไทม์):** [https://youtu.be/gk9c903LHlo](https://youtu.be/gk9c903LHlo)

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "driver/adc.h"
#include "esp_log.h"

#define ADC_MIN     0
#define ADC_MAX     2730
#define DEG_MAX     180

/**
 * @brief ฟังก์ชันแปลงค่า Raw ADC เป็นมุมองศาแบบจำนวนเต็ม (มองด้วยสายตาเปล่า)
 */
int adc_to_angle(int adc)
{
    if (adc <= ADC_MIN) return 0;
    if (adc >= ADC_MAX) return DEG_MAX;
    
    // คำนวณเชิงเส้นและปัดเศษเป็นจำนวนเต็ม
    float angle = ((float)(adc - ADC_MIN) * DEG_MAX) / (float)(ADC_MAX - ADC_MIN);
    return (int)(angle + 0.5f);
}

void app_main(void)
{
    // กำหนดความละเอียด ADC = 12 bit (0-4095)
    adc1_config_width(ADC_WIDTH_BIT_12);

    // กำหนด Channel 6 (GPIO34) และ Attenuation 11dB
    adc1_config_channel_atten(ADC1_CHANNEL_6, ADC_ATTEN_DB_11);

    while (1) {
        int adc = adc1_get_raw(ADC1_CHANNEL_6);
        int angle = adc_to_angle(adc);

        printf("ADC = %d  Angle = %d deg\n", adc, angle);
        vTaskDelay(pdMS_TO_TICKS(300));
    }
}
```

### ขั้นตอนที่ 7: ตรวจสอบความแม่นยำและการวิเคราะห์ความคลาดเคลื่อน (Accuracy Verification)

จากการหมุนทดสอบตำแหน่งต่างๆ ตามขีดหน้าปัดบนกระดาษที่สังเกตด้วยสายตา เปรียบเทียบกับมุมที่โปรแกรมแสดงผล:

$$\text{Absolute Error } (\Delta \theta) = |\theta_{measured} - \theta_{actual}|$$

$$\% \text{Error} = \frac{|\theta_{measured} - \theta_{actual}|}{\theta_{max}} \times 100\%$$

| มุมจริงบนกระดาษ ($\theta_{actual}$) | ค่า Raw ADC จากคลิป | มุมที่โปรแกรมแสดงผล ($\theta_{measured}$) | Absolute Error ($|\Delta\theta|$) | % Error (เทียบ Full Scale 180°) |
| :---: | :---: | :---: | :---: | :---: |
| **0°** | 0 | 0° | 0° | 0% |
| **30°** | 512 | 30° | 0° | 0% |
| **60°** | 945 | 59° | 1° | 1% |
| **90°** | 1391 | 89° | 1° | 1% |
| **120°** | 1845 | 120° | 0° | 0% |
| **150°** | 2335 | 153° | 3° | 2% |
| **180°** | 2740 | 181° | 1° | 1% |

**สรุปการประเมินความแม่นยำ:**
* **Average Absolute Error:** ประมาณ **1°**
* **ความถูกต้องแม่นยำของระบบโดยรวม (Accuracy):** สูงถึงประมาณ **99%**
* ในช่วงมุม 0° ถึง 120° ค่ามุมที่อ่านได้ตรงเป๊ะกับขีดที่มองเห็นด้วยตาเปล่าบนกระดาษ มีความคลาดเคลื่อนเล็กน้อยเพียง 1°–3° ในช่วง 150° ถึง 180° จากมุมมองสายตา (Parallax Error) และความไม่เป็นเชิงเส้นเล็กน้อยของตัวต้านทาน

## 4. สรุปผลการทดลองและการตอบคำถามท้ายใบงาน (Engineering Reflection)

1. **ทำไมต้องทำ Calibration ก่อนใช้งานเซนเซอร์อนาล็อก?**  
   เนื่องจากตัวต้านทานปรับค่าได้เชิงกล (POT) มีช่วงการหมุนกว้างถึง 270°–300° แต่หน้าปัดกระดาษที่เราวาดขึ้นมาเพื่อใช้งานมีช่วงเพียง 0°–180° หากเราไม่ทำการ Calibration เพื่อหาจุดต่ำสุด ($ADC_{min}$) และจุดสูงสุด ($ADC_{max}$) เราจะไม่สามารถแปลงค่าดิจิทัลดิบให้ออกมาเป็นมุมองศาบนหน้าปัดที่แท้จริงได้ การทำ Calibration จึงช่วยจับคู่สัญญาณไฟฟ้าเข้ากับสเกลทางกายภาพที่เรามองเห็นได้อย่างสมบูรณ์

2. **สาเหตุของความคลาดเคลื่อนในการทดลอง:**
   * **มุมมองสายตา (Parallax Error):** การเล็งแนวเข็มชี้ให้ตรงกับเส้นขีดบนกระดาษด้วยตาเปล่า อาจมีความคลาดเคลื่อนประมาณ 1°–2° ตามองศาการมอง
   * **การเยื้องศูนย์กลาง (Mechanical Misalignment):** การเจาะรูกระดาษเพื่อสอดแกน POT อาจไม่ตรงจุดกึ่งกลางของวงกลมพอดี ทำให้รัศมีการกวาดมุมเบี้ยวเล็กน้อย
   * **คุณสมบัติ Non-linearity ของ POT และ ADC:** สารเคลือบคาร์บอนบนตัว POT และวงจร ADC ของ ESP32 อาจมีความไม่เป็นเส้นตรงเล็กน้อยในช่วงปลายสเกล

3. **แนวทางการปรับปรุงระบบ:**
   * ใช้ไม้บรรทัดวัดระยะหรือเข็มชี้ที่แหลมและยาวขึ้นเพื่อลดความคลาดเคลื่อนในการมองด้วยสายตา
   * เพิ่มตัวเก็บประจุ (Capacitor $0.1\mu\text{F}$) คร่อมขากลางของ POT กับ GND เพื่อกรองสัญญาณรบกวนทางไฟฟ้าให้ค่านิ่งยิ่งขึ้น
